## 💻 Sobre o Projeto

O **Fogo-Zero** é um projeto socioambiental que visa combater o avanço das queimadas irregulares e proteger o meio ambiente. A plataforma oferece conteúdo educativo sobre os impactos das queimadas, canal para envio de denúncias, sistema de alertas para a população e cadastro de usuários engajados na causa.

---

## ✨ Funcionalidades

- 📢 **Canal de Denúncias:** Formulário simples para registro e reporte de focos de incêndio ou queimadas ilegais.
- 🚨 **Central de Alertas:** Envio de avisos de risco de incêndio para a comunidade local.
- 📚 **Conteúdo Educativo:** Seção informativa com orientações de prevenção e conscientização ambiental.
- 👤 **Autenticação de Usuários:** Páginas dedicadas de login e cadastro.
- ℹ️ **Quem Somos:** Informações sobre a missão e a equipe por trás do projeto.
